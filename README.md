# LC-RADAR-GPLinker

本仓库为论文《面向肺癌中医医案的关系抽取数据集构建与 LC-RADAR-GPLinker 模型研究》的配套代码与数据说明，主要包含 **LC-TCMRE 数据集** 及 **LC-RADAR-GPLinker 模型实现**。

## 1. 项目简介

肺癌中医医案中包含症状、证型、治法、方剂、处方用药、检查及检查结果等多类临床信息，实体关系复杂，人工结构化整理成本较高。为此，本文构建了面向肺癌中医医案关系抽取任务的数据集 **LC-TCMRE**，并提出 **LC-RADAR-GPLinker** 模型，用于从医案文本中自动抽取结构化 SPO 三元组。

LC-RADAR-GPLinker 以 GPLinker 为基础框架，主要包含三个改进模块：

* **RSCD**：关系选择性约束解码模块；
* **HNRT**：难负样本鲁棒训练模块；
* **DERAF**：领域增强关系自适应融合模块。

LC-TCMRE 数据集面向肺癌中医医案文本构建，采用 SPO 三元组形式标注实体间关系。数据集共包含 7 类关系：

| 关系类型    | 主体实体 | 客体实体 |
| ------- | ---- | ---- |
| 检查-检查结果 | 检查   | 检查结果 |
| 症状-证型   | 症状   | 证型   |
| 中医病名-证型 | 中医病名 | 证型   |
| 证型-治法   | 证型   | 治法   |
| 证型-方剂   | 证型   | 方剂   |
| 治法-方剂   | 治法   | 方剂   |
| 方剂-处方用药 | 方剂   | 处方用药 |

## 3. 模型方法

LC-RADAR-GPLinker 在 GPLinker 基础上进行改进，整体思路如下：

1. 使用 LC-TCM-BERT 对肺癌中医医案文本进行编码；
2. 利用 GPLinker 预测实体跨度、主体-客体 head 链接和 tail 链接；
3. 在推理阶段通过 RSCD 对候选三元组进行关系特异性约束解码；
4. 在训练阶段通过 HNRT 强化模型对困难负样本的判别能力；
5. 通过 DERAF 融合关系约束分支与领域增强分支的预测结果，得到最终 SPO 三元组。

## 4. 实验结果

LC-RADAR-GPLinker 在 LC-TCMRE 测试集上取得了较优性能：

| 模型                     |     P |     R |    F1 |
| ---------------------- | ----: | ----: | ----: |
| GPLinker               | 68.38 | 82.34 | 74.71 |
| GPLinker + RSCD        | 70.23 | 82.77 | 75.99 |
| GPLinker + RSCD + HNRT | 74.94 | 80.69 | 77.71 |
| LC-RADAR-GPLinker      | 75.33 | 83.08 | 79.01 |
